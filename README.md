# 王宇晨 & 周婷 · 婚礼请柬

印象派花园风的婚礼请柬单页,纯静态 HTML/CSS/JS,无任何依赖,扔到任意静态托管即可访问。

## 目录结构

```
e:\wedding
├── index.html          页面主体
├── css/style.css       印象派花园风样式
├── js/main.js          交互脚本 + 内容配置区
├── images/
│   ├── wedding/        婚纱照 w01.jpg ~ w58.jpg(已压缩)
│   └── hotel/          酒店照片 hotel-1.jpg / hotel-2.jpg
└── music/              背景音乐(bgm.mp3,见目录内 README.txt)
```

## 修改内容(不用懂代码)

所有可改内容集中在 `js/main.js` 顶部 `CONFIG` 对象里:

| 想改什么 | 怎么做 |
|---|---|
| 新人姓名 | 改 `groom` / `bride` |
| 婚礼时间 | 改 `weddingDate`(格式 `YYYY-MM-DDTHH:mm:ss+08:00`) |
| 酒店名称/地址 | 改 `hotelName` / `hotelAddress` |
| 婚礼流程 | 增删 `schedule` 数组里的 `{time, title, desc}` |
| 周边景点 | 增删 `travel` 数组里的 `{name, dist, desc}` |
| 封面背景照 | 改 `coverImage`(填 `images/` 下的任意照片路径) |
| 婚纱照分组 | 把照片按造型放进 `images/wedding/` 下的子文件夹,每组建 `first.jpg` 作封面;整理好后由 Claude 扫描生成 `albums` 配置并压缩照片 |
| 出席登记 | 云端模式(推荐):配置 `cloudbaseEnv` 后为页内表单,数据进 rsvp 集合;未配置时跳转腾讯文档(`rsvpUrl`) |
| 座位名单 | 云端模式:维护 CloudBase `seats` 集合(可 CSV 导入,模板见 `guest/seats-导入模板.csv`);降级模式:改 `seats` 数组 |
| 婚礼菜单 | 替换 `menu` 数组(按分类组织 `{cat, items: [{name, note}]}`) |
| 背景音乐 | 把音乐文件命名为 `bgm.mp3` 放进 `music/` 目录 |

## 功能清单

- 信封开场:打开页面先显示信封,点击拆封、信纸滑出并展开邀请卡(内容:尊敬的宾客称呼 + 时间地点新人信息),收起后进入首页;同一会话内刷新不重复播放
- 宾客称呼支持 URL 参数:分享链接带 `?guest=张三`,信纸上就显示"尊敬的 张三",不带参数默认"亲朋好友"
- 首页:整屏照片背景 + 新人姓名/日期/倒计时 + 6 个子项目入口卡片(点击平滑跳转到对应模块)
- 单页下滑浏览全部模块:流程 → 位置 → 指南 → 周边 → 祝福 → 婚纱照(最后);顶部导航随滚动高亮,可随时点击跳转
- 婚礼指南板块:出席登记(跳转腾讯文档收集表)、座位查询(输姓名查桌号)、婚礼菜单(分组列表)
- 婚纱照按造型分组:每组一张封面大卡(诗句标题叠加) + 瀑布流网格,点击放大(放大层支持左右切换/滑动/键盘/全屏)
- 婚礼流程垂直时间轴
- 酒店位置:照片放大查看 + 高德/百度一键导航(免 API key,自动唤起地图 App)
- 周边景点卡片,点击跳转高德地图搜索
- 婚礼倒计时(首页显示,到点清零)
- 背景音乐(首次点击页面后自动播放,右上角可开关)
- 宾客祝福留言(存本机 localStorage)
- 花瓣飘落动画

## 云端数据(CloudBase)

页面支持接入腾讯云开发 CloudBase,把出席登记、座位查询、祝福留言统一上云:

1. 打开 console.cloud.tencent.com/tcb → 开通云开发 → 创建环境(按量计费,有免费额度)
2. 记下**环境 ID**,填入 `js/main.js` 的 `CONFIG.cloudbaseEnv`
3. 环境 → 登录授权 → 开启「匿名登录」
4. 数据库 → 创建三个集合:
   - `rsvp`(出席登记)权限:「所有用户可读,仅创建者可读写」
   - `wishes`(祝福留言)权限:同上
   - `seats`(座位名单)权限:「所有用户可读」(名单由你在控制台维护/CSV 导入)
5. 本地测试:`node scripts/serve.js` 后访问 http://localhost:8080
   (云开发要求 http 协议,直接双击 file:// 打开无法连云端)

未配置 `cloudbaseEnv` 时,页面自动降级:登记跳转腾讯文档、留言存本机、座位用内置名单。

## 部署

项目是纯静态的,全部用相对路径,可以整目录丢到任意静态托管:

- **国内免费**:Gitee Pages(需实名)、腾讯云/阿里云 OSS 静态网站托管(域名需备案)
- **国外免费**:GitHub Pages / Cloudflare Pages(国内访问速度一般)
- **已有服务器**:Nginx/Caddy 指到本目录即可

部署后把网址发给宾客,微信内直接打开。

## 微信分享卡片说明

页面已写好 og:title / og:description 标签,部分场景(如从浏览器分享)会显示标题摘要。
在微信内要实现自定义分享卡片(标题+封面图),需要已认证的公众号配合微信 JS-SDK,
纯静态页面无法独立实现——若之后需要,可在已部署的域名下接入 JS-SDK。
